# Frontend (owner: Timo)

Next.js (App Router, TypeScript), Tailwind 3, MapLibre (from build step 4). Spec: `docs/SCOPE_3_FRONTEND.md`. Open points: `context/OPEN_FRONTEND_QUESTIONS.md`.

```bash
cd frontend
npm install
cp .env.example .env.local   # NEXT_PUBLIC_MODE=mock | live | demo
npm run dev                  # http://localhost:3000, copies contracts/fixtures first
npm run build && npm start   # production build (build online once; fonts are self-hosted afterwards)
npm run typecheck
```

Demo for the pitch (M4 Air, Wi-Fi off). `NEXT_PUBLIC_*` values are baked in at build time, so set them for the build:

```bash
# backend first (Said): AGENT_OFFLINE=1 uvicorn agent.server.app:app --port 8000, with data/ (results + tiles)
NEXT_PUBLIC_MODE=demo NEXT_PUBLIC_API_URL=http://localhost:8000 npm run build
npm start                    # http://localhost:3000
```

On the Analyse screen: "Analyse erneut abspielen" restarts the replay, "Nächste Karte" goes to the next `/demo` card in pitch order.

- `lib/api.ts` is the only file that fetches. It switches on `NEXT_PUBLIC_MODE`.
- `lib/types.ts` mirrors `contracts/schemas/`.
- `public/fixtures/` is generated by `npm run fixtures`; never edit it.
- Design tokens: `app/globals.css` (CSS variables, sz.ch family values from `docs/FRONTPAGE_PLAN.md` 2.1) and `tailwind.config.ts`. The theme replaces Tailwind's defaults on purpose: radius stops at 4px (no pill badges), no shadows except the focus ring.
